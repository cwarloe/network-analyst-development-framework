Wireshark: pull out the fields you need
A short primer for Lessons 03, 04 and 06
Name a field  •  Filter on it  •  Pull it out
Follows Wireshark: a first look  ·  uses 03-dns.pcap and 04-tls.pcap from this course
Lessons 03, 04 and 06 pull single fields out of packets. This video covers how.
STEP 1Every field has a name
  • 1Click a field in the details pane.
  • 2Read the status bar. The name in brackets is the field's name for filters.
  • 3Or right-click the field and choose Copy → Fieldname.
The text in the details pane is a label. The name in brackets is what you type.
STEP 2Filter on a protocol
  • 1Type just a protocol name: tls.
  • 2Press Enter. Only packets that contain that protocol stay.
  • 3The status bar counts them: 13 of 29.
A protocol name alone keeps every packet that has that protocol in it.
STEP 3Filter on a field's value
  • 1Write protocol.field, then ==, then a value.
  • 2Handshake type 1 is the Client Hello. Two packets match.
  • 3Same colors as before: red until the filter is complete.
Name the field, compare it to a value, and only matching packets remain.
STEP 3bNumbers pick a conversation or a port
  • 1tcp.stream == 0 keeps one TCP conversation. Streams are numbered from 0.
  • 2udp.port == 53 matches the port on either side, source or destination.
On 03-dns.pcap, udp.port == 53 keeps 16 of 16 packets: every packet there is DNS on port 53.
Follow → TCP Stream sets a filter like this for you. You can also type it.

Copy ▸
  • 1Click the field in the details pane.
  • 2Right-click it and choose Apply as Column.
  • 3Every packet now shows that field's value in the list.
  • 4To undo it: right-click the column heading → Remove Column.
A column puts one field's value for every packet side by side.
NO GUI?Pull out fields with tshark
  • 1-T fields prints only the fields you ask for.
  • 2Add one -e for each field, in the order you want the columns.
  • 3Columns are separated by tabs. These are the same names as in Wireshark.
One row per packet. One column per -e.
READ THE ROWSBlank cells and commas
  • 1A blank cell means that packet has no such field.
  • 2A comma means the packet has the field more than once.
  • 3Filter with -Y and pick fields with -e in the same command.
Frame 6 has several values. Frames 10 and 11 have none. Both are normal.
SEE EVERYTHINGtshark -V shows one packet in full
  • 1-V prints the whole details tree, as Wireshark's details pane shows it.
  • 2Pick one packet with -Y, or the output is very long. Here, … marks lines cut for space.
  • 3It shows labels, such as Name. To filter or extract, you still need the field name.
Use -V to look. Use -T fields to extract.
