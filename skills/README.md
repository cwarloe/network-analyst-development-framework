# Skills

Portable material extracted from this project, packaged so it can be used elsewhere.

## `technical-training-design`

The instructional-design evidence base and the process lessons, distilled from [R005](../docs/research/R005-instructional-design-review.md), [R006](../docs/research/R006-literature-scan.md), [R008](../docs/research/R008-longitudinal-judgment.md) and [R009](../docs/research/R009-reviewer-agreement.md) and from what building this course actually cost.

Everything project-specific is stripped: no NICE mapping, no capture licensing, no network content. What remains is what applies to any attempt to teach judgment in a technical domain.

**The confidence markers came with it deliberately.** The underlying scans were commissioned from research models and their sources were not independently read; the records here say so, and so does the skill. A version that presented these as settled findings would launder the caveats away, which is the thing this curriculum teaches people not to do.

Kept here because `~/.claude/skills/` does not survive a rebuilt environment and this repository does.

To install it, copy the directory into `~/.claude/skills/`.
